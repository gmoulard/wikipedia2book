# Wikipedia2Book and mediawiki2latex: comparison

As of 15 November 2026.

- **Wikipedia2Book 1.7.5**: version on `main` (`app/version.py`), described by `docs/SPECIFICATIONS.en.md`.
- **mediawiki2latex**: version of the web service `mediawiki2latex.wmcloud.org` and of the author's manual (Dirk Hünniger, Wikibooks page last edited on 9 July 2025). The service does not show a version number. The latest version published on Hackage is 7.33 (January 2019); Debian sid offers an 8.7 package, not checked here (Debian site unreachable).

## 1. Approach

| | Wikipedia2Book | mediawiki2latex |
|---|---|---|
| Approach | Assembles the **official Wikipedia PDFs** (`/api/rest_v1/page/pdf/…`) without rebuilding their content, and adds a cover, table of contents, chapters, licence and conclusion | **Converts** the MediaWiki wikitext or HTML to LaTeX, then compiles that LaTeX |
| Faithfulness to the Wikipedia rendering | Exact: text, images and references are those of the Wikipedia PDF | Re-typeset: uniform LaTeX rendering, but unknown templates are rendered badly or not at all |
| Typography | That of each Wikipedia PDF, plus that of the pages generated by WeasyPrint | A single LaTeX typography for the whole book, with hyphenation |
| Technology | Python (FastAPI, WeasyPrint, pypdf, reportlab), JavaScript interface without a framework | Haskell, TeX Live, ImageMagick, LibreOffice, calibre, Chromium |
| Software licence | AGPL-3.0 | GPL |

## 2. Accepted sources

| | Wikipedia2Book | mediawiki2latex |
|---|---|---|
| Single article | Yes (URL, title, or search with suggestions as you type) | Yes (URL) |
| Wikipedia book page (`Book:`, `User:…/Books/…`) | Yes: page order kept, `;` chapters, `===` subtitle | Yes ("Book / Collection" and "Book Contents Page" modes) |
| Free list of pages (one per line, `[[…]]`, Markdown, `nl:Title`) | Yes, multilingual within the same book | No |
| Exploring linked articles | Yes: links of an article in page order, added by hand | Indirect: the "Book / Collection" mode follows all the links of the first page, one level deep, without choice |
| Other wikis (Wikibooks, Wikiversity, non-Wikimedia MediaWiki wikis) | No: Wikipedia only | Yes, any wiki written in wikitext |
| Personal documents (images, PDFs) | Yes, up to 15 MB per file, organised like articles | No |
| Specific revision of an article (`oldid`) | No: always the current version | Not documented |

## 3. Book organisation

| | Wikipedia2Book | mediawiki2latex |
|---|---|---|
| Order of articles and chapters | Drag and drop in the interface | Defined only by the source book page |
| Position of the table of contents | Free choice (start, end, before any item), or removed | Fixed, that of the LaTeX template |
| Cover, introduction, conclusion | Yes, entered in the interface (introduction and author suggested from the first article) | No |
| Saving and resuming a book | Export then import of a JSON file | No: each conversion starts again from the source page |

## 4. Layout

| | Wikipedia2Book | mediawiki2latex |
|---|---|---|
| Paper sizes | A0 to A6, Letter, Legal, custom (mm) | A4, A5, B5, Letter, Legal, Executive |
| Orientation | Portrait or landscape | No choice offered |
| Margins | 4 presets or millimetre setting, binding margin | Those of the LaTeX template (editable locally) |
| Fitting to the paper size | Wikipedia pages scaled and centred; native in A4, Letter and Legal | Native typesetting in the chosen size |
| Page numbering | Yes, continuous over the whole book, can be turned off | Yes (LaTeX) |
| Tables | Those of the Wikipedia PDF | Typeset by Chromium or by LaTeX, as chosen |
| Images | Those of the Wikipedia PDF | Resolution capped (300 dpi by default, adjustable on the command line), SVG rasterised or kept as vector |
| Mathematical formulas | Those of the Wikipedia PDF | Typeset by LaTeX |

## 5. Navigation, licences and credits

| | Wikipedia2Book | mediawiki2latex |
|---|---|---|
| PDF bookmarks | Cover, table of contents, chapters, articles, licence, conclusion | Those produced by LaTeX (sections) |
| Table of contents links | Clickable internal links | Yes (LaTeX) |
| Cross-references between articles of the book | No: article links point to the web | Not documented |
| Licence page | Yes: CC BY-SA 4.0, URL and history of each article, translated into the interface language | Contributors of each article |
| Image credits | Those printed by Wikipedia in each PDF | List of figures in an appendix, with author and licence read from each file's page (`Information` template) |

## 6. Output formats

| | Wikipedia2Book | mediawiki2latex |
|---|---|---|
| PDF | Yes | Yes |
| LaTeX sources (zip) | No | Yes |
| EPUB | No | Yes (EPUB2) |
| ODT (word processor) | No | Yes |

## 7. Usage

| | Wikipedia2Book | mediawiki2latex |
|---|---|---|
| Online service | `wikipedia2book.toolforge.org` (Toolforge), also Northflank | `mediawiki2latex.wmcloud.org` (Wikimedia Cloud VPS) |
| Interface | 3-step application (Sources, Organisation, Editing), 12 languages including Arabic and Persian written right to left, light and dark theme, smartphone | Single form in English: URL, output format, template expansion, paper, tables, vector graphics |
| Generation time | The time needed to download the Wikipedia PDFs and assemble them, with a step-by-step progress window (figures in section 8) | About one minute for one article (LaTeX compiled several times), several hours for a large book |
| Service limits | At most 300 articles per book, split automatically into volumes beyond that; no time limit | 4 hours (about 2,000 pages) and 4 simultaneous conversions; a "large books" service at 12 hours (about 8,000 pages); "Not enough resources" when everything is busy |
| Local installation | Docker | Debian/Ubuntu package, Linux and Windows binaries; no time limit |
| Command line or API | HTTP API (`/api/pdf`, `/api/books/generate`, `/api/books/generate-from-wikipedia-book`…) | Full command line (`-u`, `-o`, `-p`, `-r`, `-g`, `-b`, `-d`, `-z`…) and server mode (`-s`) |
| Advanced customisation | No | Template mapping files, custom LaTeX headers, copy of the LaTeX tree for editing |
| Data kept by the server | None (the book stays in the browser) | Conversion files on the server, not documented |

## 8. Performance

Wikipedia2Book figures are measured on Toolforge (sections 13.11 and 13.12 of `docs/SPECIFICATIONS.en.md`, versions 1.9.5 to 1.11.0, 16 November 2026). mediawiki2latex figures come from its manual and the limits of its web service: they have not been measured.

| | Wikipedia2Book (measured on Toolforge) | mediawiki2latex (from its manual) |
|---|---|---|
| What is computed | Download of the official Wikimedia PDFs, then assembly, without re-typesetting their content | Conversion of the wikitext to LaTeX, then several LaTeX compilations |
| 1 article | About 1.5 s (`1-article` scenario, 4 pages) | About one minute |
| About 50 pages | 8.9 s (`50-pages` scenario) | Not published |
| About 100 pages | 16.3 s (*Wrecks of Saint-Pierre harbor*, 101 pages, version 1.9.5) | Not published |
| About 250 pages | 12.7 s (`20-articles` scenario, 253 pages) | Not published |
| Very large book | 1,500 articles, 28,072 pages: 44 minutes in 6 volumes of 250 | About 2,000 pages within the 4-hour limit; about 8,000 pages within 12 hours on the "large books" service |
| Simultaneous books | 10 books succeed (60 s each); at 20 the 2 GiB container saturates and Toolforge restarts it | 4 conversions at most, then "Not enough resources" |
| Where the time goes | Mostly downloading the PDFs from Wikimedia; the application itself takes 0.3 to 2.6 s per book. A repeated generation is faster, as Wikimedia caches the article PDFs | LaTeX typesetting of the whole book, figure list and image processing |

## 9. Summary

- **Wikipedia2Book** is faster and more faithful to the Wikipedia rendering, and gives more control over how the book is put together: choice of articles, order, chapters, cover, personal documents, paper size and margins, translated interface. It only produces PDF, cannot read other wikis and does not carry over image credits.
- **mediawiki2latex** produces a typographically uniform book, in several formats (PDF, LaTeX, EPUB, ODT), from any MediaWiki wiki, with the list of figures and their authors. On the other hand it is slow, depends on templates being converted correctly, and does not let you organise the book beyond the source page.

The gaps that Wikipedia2Book could close without giving up the official PDF are tracked in section 5 of `todo.md`.
