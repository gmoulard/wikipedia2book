# Wikipedia2Book and WS Export: comparison

As of 17 November 2026.

- **Wikipedia2Book 1.11.0**: version on `main` (`app/version.py`), described by `docs/FunctionalSpec.en.md` and `docs/TechnicalSpec.en.md`. Toolforge still serves 1.9.7, which cannot yet import a Wikisource work from its table of contents.
- **WS Export** ("Wikisource Book Export"): web service `ws-export.wmcloud.org`, its user documentation (`Wikisource:WS_Export` on Multilingual Wikisource) and the README of its source code. The service does not show a version number. The code has moved from GitHub to the Wikimedia GitLab (`toolforge-repos/wsexport`, T395398).

## 1. Approach

| | Wikipedia2Book | WS Export |
|---|---|---|
| Approach | Assembles the **official Wikimedia PDFs** (`/api/rest_v1/page/pdf/…`) without rebuilding their content, and adds a cover, table of contents, chapters, licence and conclusion | **Converts** the rendered HTML of the work into an EPUB, then converts that EPUB into the other formats with Calibre (`ebook-convert`) |
| Faithfulness to the wiki rendering | Exact: text, images and references are those of the Wikimedia PDF | Re-typeset as an ebook: the wiki's CSS is not carried over, only `MediaWiki:Epub.css` and the work's `styles.css` |
| Typography | That of each Wikimedia PDF, plus that of the pages generated by WeasyPrint | Chosen by the reader among 230 fonts |
| Technology | Python (FastAPI, WeasyPrint, PyMuPDF, pypdf, reportlab), JavaScript interface without a framework | PHP (Symfony), Calibre, a database for the contributor credits and the logs |
| Software licence | AGPL-3.0 | GPL v2 or later |
| Origin | Independent tool | Created by Tpt for French Wikisource, maintained by the Wikimedia Community Tech team; it is the download button of every Wikisource |

## 2. Accepted sources

| | Wikipedia2Book | WS Export |
|---|---|---|
| Projects | Wikipedia, Wikisource, Wikibooks, Wikivoyage, Wikiversity, Wikiquote, Wiktionary and Wikinews, mixed in one book | Wikisource only (more than 70 languages, Multilingual and Beta Wikisource) |
| Wikisource work from its table of contents | Yes (1.11.0): whole work, work and its table of contents, or the page alone; sections as chapters; "full text" pages and intermediate tables of contents skipped | Yes: links of the `ws-summary` elements of the page, otherwise all the links to subpages |
| Several works in one book | Yes | No: one work (or one section) per export |
| Personal documents (images, PDFs) | Yes, organised like articles | No |
| Elements left out | None: the Wikimedia PDF is kept as it is | Elements of class `ws-noexport` (header box, page numbers…), images on request |

## 3. Book organisation and metadata

| | Wikipedia2Book | WS Export |
|---|---|---|
| Order and chapters | Drag and drop in the interface, volumes | Those of the work's table of contents |
| Cover, introduction, conclusion | Yes, entered in the interface, cover and back page images | Nothing entered by the reader; title page from the work's metadata (not checked here) |
| Metadata (title, author, year) | Book title and author entered in the interface | Read from the microformat of the work's header template |
| Credits | Licence page: CC BY-SA, URL and history of each article | "About" page with the list of contributors (bots apart), can be excluded |
| Saving and resuming a book | JSON file, which can also be opened by a link (`?json=`) | No: each export starts again from the work |

## 4. Output formats and layout

| | Wikipedia2Book | WS Export |
|---|---|---|
| PDF | Yes: A0 to A6, Letter, Legal, custom size in mm, portrait or landscape, margins and binding margin | Yes: A4, A5, A6, Letter |
| E-reader formats | No | EPUB 2, EPUB 3, MOBI |
| Other formats | No | RTF, plain text, HTMLZ |
| Page numbering | Continuous over the whole book, can be turned off | Not documented for the PDF; none in an EPUB, whose layout depends on the reader |
| Table of contents | Clickable, at the start or the end, or removed | That of the EPUB, from the work's table of contents |

## 5. Performance

Wikipedia2Book figures are measured on Toolforge (sections 13.11 and 13.12 of `docs/TechnicalSpec.en.md`, versions 1.9.5 to 1.11.0, 16 November 2026). WS Export figures come from the Community Tech "Ebook Export Improvement" page on Meta-Wiki: they have not been measured on the same books.

| | Wikipedia2Book (measured on Toolforge) | WS Export (published by Community Tech) |
|---|---|---|
| What is computed | Download of the official Wikimedia PDFs, then assembly | HTML of every page of the work converted into an EPUB, then Calibre for the other formats |
| Typical time | About 1.5 s for one article; 8.9 s for about 50 pages; 12.7 s for about 250 pages | Median of 3 s per export, over one month of exports, all formats together |
| Very large book | 1,500 articles, 28,072 pages: 44 minutes in 6 volumes of 250 | Not published; timeouts reported by users |
| Cache | None on the server (stateless); Wikimedia caches the article PDFs, so a repeated generation is faster | Exported files kept in cache: a book downloaded again soon after is much faster |
| What slows it down | Downloading the PDFs from Wikimedia (at most 4 at a time on Toolforge); the application itself takes 0.3 to 2.6 s per book | The contributor credits, hence the "Exclude editor credits (faster download)" option; Calibre for PDF |

## 6. Usage

| | Wikipedia2Book | WS Export |
|---|---|---|
| Online service | `wikipedia2book.toolforge.org` (Toolforge), also Northflank | `ws-export.wmcloud.org`, and the download links of each Wikisource |
| Interface | 3-step application (Sources, Organisation, Editing), 12 languages including Arabic and Persian | Single form: Wikisource, title, format, font, options; translated on translatewiki.net |
| Command line or API | HTTP API (`/api/pdf`, `/api/pdf/from-json`…) | Export URL with parameters; console commands for a local installation (batch downloads) |
| Local installation | Docker | PHP and Composer, Calibre for formats other than EPUB, Docker for development |
| Data kept by the server | None (the book stays in the browser) | Cache of exported books, logs (public SQL dumps) |

## 7. Summary

- **WS Export** is the natural choice for **reading** a Wikisource work: e-reader formats, choice of font, fast thanks to its cache, available from every Wikisource page. It only exports one work at a time, from Wikisource only, and re-typesets it.
- **Wikipedia2Book** is aimed at a **printed book** put together by the reader: several works and projects, chapters, cover, introduction, personal documents, paper size and margins, continuous page numbering, with the Wikimedia rendering kept as it is. It only produces PDF.
