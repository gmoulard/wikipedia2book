# ヘルプ：「本を作る」欄には何を入力できますか？

最初のステップの入力欄は、記事のタイトルだけでなく、アドレス、本全体、ページの一覧、ブックページのテキストも受け付けます。追加したいものを入力または貼り付けて、「追加」をクリックしてください。追加したページは入力欄の下に表示され、次のステップで並べ替えます。

## 早見表

| 追加したいもの | 入力するもの | 例 |
|---|---|---|
| タイトルがわかっている記事 | そのタイトル | `Montagne Pelée` |
| 特定のページ | そのアドレス | `https://fr.wikipedia.org/wiki/Épaves_de_la_rade_de_Saint-Pierre` |
| 別の言語の記事 | 言語コード、コロン、タイトル | `nl:Rotterdam` |
| ほかのウィキメディア・プロジェクトのページ | プロジェクトの接頭辞、続いてタイトル | `voy:en:Lyon` |
| 本全体 | 目次ページまたはブックページのアドレス | `https://fr.wikibooks.org/wiki/Cosmologie` |
| 複数のページを一度に | 1 行に 1 ページ | 「複数のページを一度に追加」を参照 |
| 「ブック:」ページで用意された本 | そのページのテキスト | 「ブックページのテキストを貼り付ける」を参照 |

## 記事を探す

- 何文字か入力すると、入力欄の下に候補が表示されます。
- 入力欄の横の一覧で、どの言語のウィキペディアを検索するかを選びます。「すべて」を選ぶと一覧のすべての言語でタイトルを検索し、各結果にその言語が表示されます。
- タイトルが記事と完全に一致すれば、そのまま追加されます。別の記事へのリダイレクトになっているタイトルは、転送先の記事を追加します。`Napoléon Bonaparte` は「Napoléon Ier」を追加します。
- 一致しない場合は、検索結果が入力欄の下に表示されるので、必要なものをクリックします。
- 最初に追加した記事の序文とページの作成者が、「編集」ステップで本の序文と著者として提案されます。変更できます。

## 別の言語やほかのプロジェクトのページ

完全なアドレスは常に使えます。例：`https://fr.wikivoyage.org/wiki/Lyon`。タイトルの場合は、前に言語の接頭辞、プロジェクトの接頭辞、またはその両方を付けます。

| プロジェクト | 接頭辞 | 例 |
|---|---|---|
| 別の言語のウィキペディア | 言語コード | `nl:Rotterdam` |
| ウィキソース | `s:` | `s:Les Misérables` |
| ウィキブックス | `b:` | `b:Cosmologie` |
| ウィキボヤージュ | `voy:` | `voy:en:Lyon` |
| ウィキバーシティ | `v:` | `v:Python` |
| ウィキクォート | `q:` | `q:Victor Hugo` |
| ウィクショナリー | `wikt:` | `fr:wikt:chat` |
| ウィキニュース | `n:` | `n:Accueil` |

言語コードがない場合は、入力欄の横で選んだ言語が使われます。接頭辞の順序は問いません。各ページのカードには、そのプロジェクト名と言語が表示されたままになります。

## 本全体

- **ウィキペディアのブックページ**：アドレスまたは名前を入力します。例：`Utilisateur:Alexbzh972/Livres/Martinique`。すべての記事がページの順序どおりに、章、タイトル、副題とともに追加されます。
- **ウィキブックスのコンピレーション**：コンピレーションのアドレスを入力します。例：`https://fr.wikibooks.org/wiki/Wikilivres:Compilations/Programmation_C`。ウィキペディアのブックページと同じように、一覧の順序でページが追加されます。
- **ウィキブックスの本やウィキソースの作品**：目次ページのアドレスまたはタイトルを入力します。例：`https://fr.wikibooks.org/wiki/Cosmologie` や `s:Les Misérables`。ウィンドウで何を追加するかを尋ねられます。
  - 「本全体」：すべてのページを章に分けて追加；
  - 「本全体とその目次」：同じ内容に、目次ページを先頭に加える；
  - 「このページのみ」：目次ページだけ；
  - 「キャンセル」：何も追加しない。
- **ウィキブックスの印刷用版**：その本の「印刷用版」ページのアドレスを入力します。例：`https://fr.wikibooks.org/wiki/Programmation_C/Version_imprimable`。そのページが手書きなら、見出しごとに 1 章としてページが追加されます。目次ページから自動生成されている場合は、本の選択ウィンドウが開きます。

## 複数のページを一度に追加

1 行に 1 ページの一覧を貼り付けます（入力中に改行するには Shift+Enter）。各行はタイトル、アドレス、接頭辞付きのページのどれでもよく、ウィキリンク、Markdown リンク、番号付きまたは箇条書きの項目として書くこともできます。

```
[[Brest]]
[[nl:Amsterdam]]
[Suchet](https://fr.wikipedia.org/wiki/Suchet_(navire))
1. Lorient
* Concarneau
[[voy:en:Lyon]]
fr:wikt:chat
```

最後に、追加されたページ数、すでに本にあったページ数、見つからなかったページ数がメッセージで表示されます。見つからなかった行は修正できるように入力欄に残ります。一覧に本の目次ページがあると、上で説明した選択ウィンドウが開きます。

## ブックページのテキストを貼り付ける

ウィキペディアの「ブック:」ページの内容を貼り付けることができます。`== … ==` がタイトル、`=== … ===` が副題になり、`;` の行がそれぞれ章を始め、`[[…]]` のリンクがそれぞれ記事を追加します。

```
== Ports bretons ==
=== Guide des ports ===
:[[Brest]]
;Finistère
:[[Concarneau]]
:[[Douarnenez]]
;Morbihan
:[[Lorient]]
```

`{{:…}}` の読み込みで構成されたウィキブックスの印刷用版のテキストも同じように受け付けます。`= … =` の見出しがそれぞれ章になります。

## 保存した本や共有された本を開く

- 「保存」ボタンで本をファイルとしてダウンロードし、「開く」ボタンで後から読み込み直せます。サーバーには何も残りません。このファイルが唯一のバックアップです。
- `https://wikipedia2book.toolforge.org/?json=https://…` の形式のリンクは、オンラインに保存された本を開きます（`https://` のアドレスのみ）。
- `https://wikipedia2book.toolforge.org/?source=…` の形式のリンクは、そのソースを入力したのと同じように追加します。ページの選択を共有するのに便利です。

## 入力欄が受け付けないもの

- ウィキメディア・プロジェクトではないサイト
- 記事ではないページ（ノート、ヘルプ、コミュニティのページ）
- ウィキメディア・コモンズのファイル：代わりに「構成」ステップで文書として、または「編集」ステップで背景画像として追加してください
- 存在しないページ

エラーメッセージが問題を説明します。メッセージはサーバーから返され、インターフェースの言語にかかわらずフランス語のままです。

## その次は？

- **構成**：ページを並べ替え、章を作り、自分の画像や PDF を追加し、本を巻に分けます。300 記事を超えると、本は自動的に巻に分けられます。
- **編集**：タイトル、表紙、背景画像、目次、判型、余白。
- **PDF を生成**：各記事はウィキペディアが印刷するとおりに収録され、全体が印刷できる 1 冊の本になります。
