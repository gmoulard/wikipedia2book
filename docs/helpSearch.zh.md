# 帮助：“构建图书”输入框里可以输入什么？

<!-- {% raw %} -->

第一步的输入框接受的远不止条目标题：地址、整本书、页面列表，或图书页面的文本都可以。输入或粘贴想要添加的内容，然后点击“添加”。添加的页面会显示在输入框下方；下一步再整理它们。

## 一览

| 想要添加… | 输入… | 示例 |
|---|---|---|
| 已知标题的条目 | 标题 | `Montagne Pelée` |
| 某个特定页面 | 页面地址 | `https://fr.wikipedia.org/wiki/Épaves_de_la_rade_de_Saint-Pierre` |
| 其他语言的条目 | 语言代码、冒号、标题 | `nl:Rotterdam` |
| 其他维基媒体项目的页面 | 项目前缀，然后是标题 | `voy:en:Lyon` |
| 其他网站的图片、PDF 或网页，或维基共享资源的文件 | 它的网址：它会成为书中的一个文档，标为“互联网网址” | `https://commons.wikimedia.org/wiki/File:Montagne_Pelée_1902.jpg` |
| 整本书 | 目录页或图书页面的地址 | `https://fr.wikibooks.org/wiki/Cosmologie` |
| 一次添加多个页面 | 每行一个页面 | 见“一次添加多个页面” |
| 在“图书:”页面上准备好的书 | 该页面的文本 | 见“粘贴图书页面的文本” |

## 搜索条目

- 输入几个字母：输入框下方会出现建议。
- 输入框旁的列表用于选择在哪种语言的维基百科中搜索。选择“全部”时，会在列表中的所有语言里搜索该标题，每个结果都标明其语言。
- 如果标题与某个条目完全一致，会直接添加。重定向到其他条目的标题会添加目标条目：`Napoléon Bonaparte` 会添加“Napoléon Ier”。
- 否则，搜索结果会显示在输入框下方：点击想要的结果即可。
- 添加第一篇条目时，它的简介和页面创建者会在“编辑”步骤中被建议作为本书的简介和作者。你可以修改。

## 其他语言或其他项目的页面

完整地址总是可用，例如 `https://fr.wikivoyage.org/wiki/Lyon`。使用标题时，在前面加上语言前缀、项目前缀或两者：

| 项目 | 前缀 | 示例 |
|---|---|---|
| 其他语言的维基百科 | 语言代码 | `nl:Rotterdam` |
| 维基文库 | `s:` | `s:Les Misérables` |
| 维基教科书 | `b:` | `b:Cosmologie` |
| 维基导游 | `voy:` | `voy:en:Lyon` |
| 维基学院 | `v:` | `v:Python` |
| 维基语录 | `q:` | `q:Victor Hugo` |
| 维基词典 | `wikt:` | `fr:wikt:chat` |
| 维基新闻 | `n:` | `n:Accueil` |

没有语言代码时，使用输入框旁选择的语言。前缀的顺序无关紧要。每个页面在卡片上保留其项目名称和语言。

## 整本书

- **维基百科图书页面**：输入其地址或名称，例如 `Utilisateur:Alexbzh972/Livres/Martinique`。所有条目按页面中的顺序添加，并带有章节、标题和副标题。
- **维基教科书的汇编**：输入汇编的地址，例如 `https://fr.wikibooks.org/wiki/Wikilivres:Compilations/Programmation_C`。其中的页面按列表顺序添加，与维基百科图书页面相同。
- **维基教科书的书或维基文库的作品**：输入其目录页的地址或标题，例如 `https://fr.wikibooks.org/wiki/Cosmologie` 或 `s:Les Misérables`。会弹出窗口询问：
  - “整本书”：所有页面，按章节排列；
  - “整本书及其目录”：同上，目录页放在最前；
  - “仅此页面”：只有目录页；
  - “取消”：不添加任何内容。
- **维基教科书的可打印版本**：输入该书“可打印版本”页面的地址，例如 `https://fr.wikibooks.org/wiki/Programmation_C/Version_imprimable`。如果该页面是手写的，其页面会按每个标题一章添加；如果它由目录页生成，则会打开该书的选择窗口。

## 一次添加多个页面

粘贴一个列表，每行一个页面（输入时换行请用 Shift+Enter）。每行可以是标题、地址或带前缀的页面，也可以写成维基链接、Markdown 链接或编号/项目符号列表项：

```
[[Brest]]
[[nl:Amsterdam]]
[Suchet](https://fr.wikipedia.org/wiki/Suchet_(navire))
1. Lorient
* Concarneau
[[voy:en:Lyon]]
fr:wikt:chat
```

最后会有一条消息，告诉你添加了多少页面、多少已在书中、多少未找到。未找到的行会留在输入框中，方便你修改。列表中的图书目录页会打开上面介绍的选择窗口。

## 粘贴图书页面的文本

可以粘贴维基百科“图书:”页面的内容：`== … ==` 是标题，`=== … ===` 是副标题，每个 `;` 行开始一章，每个 `[[…]]` 链接添加一篇条目。

```
== Ports bretons ==
=== Guide des ports ===
:[[Brest]]
;Finistère
:[[Concarneau]]
:[[Douarnenez]]
;Morbihan
:[[Lorient]]
```

由 `{{:…}}` 嵌入组成的维基教科书可打印版本文本也同样可以接受：每个 `= … =` 标题成为一章。

## 打开已保存或分享的图书

- “保存”按钮把你的书下载为文件；“打开”按钮之后可以重新载入。服务器不保存任何内容：这个文件是你唯一的备份。
- 形如 `https://wikipedia2book.toolforge.org/?json=https://…` 的链接会打开在线保存的书（仅限 `https://` 地址）。
- 形如 `https://wikipedia2book.toolforge.org/?source=…` 的链接会像你亲自输入一样添加其中的来源：便于分享一组页面。

## 输入框不接受的内容

- 非内容页面（讨论页、帮助页或社群页面）；
- 不存在的页面。

错误消息会说明问题所在。它来自服务器，无论界面语言如何，都保持法语。

## 接下来？

- **组织**：整理页面、创建章节、添加自己的图片或 PDF、将书分册。超过 300 篇条目时，会自动分册。
- **编辑**：标题、封面、背景图片、目录、纸张格式和页边距。
- **生成 PDF**：每篇条目都按维基百科的打印样式收录，全部内容组成一本可直接打印的书。
